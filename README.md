# zcode-skills

Мелкие скиллы для ZCode/Claude Code (SKILL.md + хелперы). Каждый — под одну
конкретную задачу, без «универсальных ассистентов».

## Список

### cvss-report
Постановка CVSS 3.1 оценки для багбаунти-репорта: чеклист метрик, частые ошибки
оценивания (забытый Scope Changed, неправильный PR) и калькулятор `cvss31.py`
с весами из официальной спеки FIRST.

```bash
python3 skills/cvss-report/cvss31.py AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
# 9.8 (critical)
```

### report-triage
Порядок триажа входящего багбаунти-репорта: воспроизведение → scope → дубликаты →
реальный импакт → CVSS → вердикт. Плюс красные флаги слабых репортов и тон ответов.
